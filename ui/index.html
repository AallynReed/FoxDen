                        Support the project

                        FoxDen is free and has no ads. If it is useful to you, a tip keeps it going.

                        Virtual microphone

                        FoxDen plays your mic, with its volume, mute, EQ and gate, into VB-CABLE, a virtual audio cable by VB-Audio. Apps then pick FoxDen VB-Cable (Microphone) as their mic.

                        VB-CABLE is VB-Audio's donationware and is installed unchanged. Windows asks for administrator rights. Settings can remove it again.

                        Keyboard shortcuts

                        Anywhere

                        Ctrl+Z
                        Undo the last effect, brightness, device or layout change
                        Ctrl+Y
                        Redo it. Ctrl+Shift+Z does the same
                        Ctrl+S
                        Save over the profile in use, or name a new one
                        Ctrl+F
                        Search effects. Arrow down goes into the list, Enter takes the first match
                        Ctrl+plus, Ctrl+minus
                        Make everything larger or smaller
                        Ctrl+0
                        Go back to 100% zoom
                        ?
